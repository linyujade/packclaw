## 二、开发环境排查与修复 `[可复现]`

### 2.1 Bug 修复：移除不存在的 fetch-debug.cjs 预加载

- `src/gateway-process.ts` 第 208 行
- **原因：** `NODE_OPTIONS: "--require fetch-debug.cjs"` 引用了 openclaw@2026.4.5 中不存在的文件，导致 Gateway 子进程启动即崩溃
- **改动：** 注释掉该行

### 2.2 开发调试过程中的临时改动（已还原，未体现在最终 diff）

以下改动在排查问题时临时修改，最终已还原为生产配置：

- **`package.json`** — 临时删除 `"officecli": "1.0.47"` 字段
  - **原因：** OfficeCLI 的 SHA256SUMS 从 GitHub 下载时 ECONNRESET，导致 `npm run package:resources` 中断
  - **还原：** 问题通过多次重试下载成功，字段已恢复

- **`.env.build`** — 临时将 `PACKCLAW_GATEWAY_ASAR=1` 改为 `0`
  - **原因：** dev 模式下代码只读散文件 `gateway/` 目录（`constants.ts` 第 198 行 `if (!app.isPackaged)` 走散文件路径），不读 `gateway.asar`。而 `.env.build` 默认开启 ASAR，导致打包产物是 `gateway.asar` 而非散文件，Electron 找不到 gateway 入口
  - **还原：** 打包发布时改回 `1`（ASAR 模式减少 69000+ 文件到单文件，Windows 冷启动从 77s 降到 10-20s）

### 2.3 排查过程中发现的已知问题（未修改，仅记录）

- **node-pty 编译失败** — kimi-claw 插件的 native addon `node-pty` 在 Windows 上 `npm rebuild` 时 `spawn EINVAL` 错误。脚本以 `⚠` 警告跳过，不影响核心功能（仅影响终端会话功能）
- **kimi-claw tgz 版本锁定** — `.env.build` 中 `PACKCLAW_KIMI_CLAW_TGZ_URL` 锁定 0.19.1 版本，因 0.20.x 在 Windows 上有 flock/ftruncate 兼容性问题
